AI PR Reviewer

Configure GitHub webhook and AI provider. Expose this app (e.g. with ngrok) and set the webhook URL in your repo.

GitHub

Required to fetch PR diffs and post review comments. Needs repo, read:org (if private org).
Set the same value in GitHub repo → Settings → Webhooks → Secret. Leave empty to skip verification.

AI Provider

Leave empty to use default (Claude Sonnet / GPT-4o).

Review limits

Larger diffs are split into batches of this size.

Webhook URL

In your GitHub repo: Settings → Webhooks → Add webhook

  • Payload URL: https://your-ngrok-url.ngrok.io/api/webhook/github
  • Content type: application/json
  • Secret: same as above
  • Events: Pull requests

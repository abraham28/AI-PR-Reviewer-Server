Connect GitHub (webhook)

Expose this app to the internet (e.g. with ngrok: ngrok http 8000), then add a webhook in your repo so GitHub can call this app on new PRs.

GitHub: Creating webhooks

In your repo: Settings → Webhooks → Add webhook

  • Payload URL: https://your-ngrok-url.ngrok.io/api/webhook/github
  • Content type: application/json
  • Secret: same as “Webhook secret” above (optional)
  • Events: Let me select individual events → check Pull requests
